ЛОГОТИПИ ПАРТНЕРІВ

Тут є п’ять заглушок partner-01.svg ... partner-05.svg.

Щоб додати свій логотип:
1. Скопіюйте файл логотипу в цю папку.
2. Відкрийте public/content.js.
3. У блоці partners → items замініть name на назву партнера,
   а logo на шлях до файлу, наприклад:
   { name: "Назва компанії", logo: "/assets/partners/nazva.png" }

Картка завжди має пропорцію 2:1. Логотип зберігає пропорції та не обрізається,
тому додавання PNG, JPG, WebP або SVG не зламає макет.
